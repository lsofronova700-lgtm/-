# Анкета удовлетворённости — «Точка роста»

Тест (анкета) удовлетворённости качеством услуг для кружков **«Робототехника»** и **«Графический дизайн»** центра «Точка роста».

- [`index.html`](index.html) — интерактивная онлайн-анкета: откройте в браузере, заполните и получите индекс удовлетворённости, разбор по разделам и пункты, требующие внимания. Ответы можно скачать в CSV (открывается в Excel) или распечатать. Работает без интернета и сервера.
- [`anketa.md`](anketa.md) — печатная версия анкеты и методика обработки результатов (индекс удовлетворённости, уровни, NPS).

Структура анкеты: сведения о респонденте → 10 общих вопросов (шкала 1–5) → 4 вопроса по робототехнике и/или 4 по графическому дизайну (показываются в зависимости от выбранного кружка) → итоговая оценка и готовность рекомендовать (0–10) → открытые вопросы.
